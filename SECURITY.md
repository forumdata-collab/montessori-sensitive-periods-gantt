# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report privately via the [GitHub Security Advisory](https://github.com/forumdata-collab/montessori-sensitive-periods-gantt/security/advisories/new) — this is a static frontend with no backend or secrets, but we still take reports seriously.

We will confirm receipt within **48 hours** and work on a fix.
